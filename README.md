# FluentStep - Android Application

This Android app project was automatically generated from **https://fluent-step-omega.vercel.app/** via **Web2APK Pro**.

## 🚀 Instant GitHub Actions Cloud APK Build
This repository is configured with automated GitHub Actions CI/CD.
1. Any commit to `main` triggers automated compilation via **JDK 17**, **Android SDK 34**, and **Gradle 8.4**.
2. Go to the **Actions** tab on your GitHub repository.
3. Select the latest completed workflow run and download the **FluentStep-v1.0.0-apk** artifact!

## 📦 Local Compilation
```bash
gradle assembleDebug
```
The APK will be located at `app/build/outputs/apk/debug/app-debug.apk`.
